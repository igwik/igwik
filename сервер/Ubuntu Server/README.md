Действия после установки

Сразу после установки Ubuntu Server 22.04 я выполняют ряд минимальный действий и настроек:
1. Актуализирую доступные пакеты в репозиториях:
sudo apt update
2. Устанавливаю доступные обновления для системы:
sudo apt upgrade
3. Устанавливаю нужную мне временную зону:
sudo timedatectl set-timezone Asia/Barnaul
Посмотреть перечень доступные временных зон можно вот такой командой:
sudo timedatectl list-timezones
4. Указываю FQDN имя хоста:
sudo hostnamectl set-hostname ubuntu.itproblog.ru
Это самый минимум настроек, который я выполняю после установки Ubuntu Server.

В современных версиях Ubuntu Server (начиная с версии 18.04 и включая 24.04 noble) за настройку сети отвечает утилита Netplan. Все конфигурационные файлы хранятся в формате YAML в директории /etc/netplan/ [1].
Ниже приведена пошаговая инструкция, как настроить сеть автоматически (DHCP) или задать статический IP-адрес вручную.
------------------------------
## Шаг 1. Узнайте имя сетевого интерфейса
Перед редактированием файлов нужно понять, как система назвала вашу сетевую карту. Выполните команду:

ip a

Ищите интерфейсы, отличные от локальной петли lo. Обычно они называются наподобие eth0, enp0s3 или ens18.
------------------------------
## Шаг 2. Найдите конфигурационный файл Netplan
Перейдите в директорию с конфигурациями:

ls /etc/netplan/

Там должен быть файл с расширением .yaml (например, 00-installer-config.yaml или 50-cloud-init.yaml). Откройте его для редактирования (замените имя файла на ваше):

sudo nano /etc/netplan/00-installer-config.yaml

------------------------------
## Шаг 3. Настройка конфигурации (выберите один из вариантов)

⚠️ Важно: Файлы YAML крайне чувствительны к пробелам. Не используйте клавишу Tab для отступов, используйте только обычные пробелы. Отступы должны быть строго друг под другом.

## Вариант А. Автоматическое получение настроек (DHCP)
Если в вашей сети работает роутер или DHCP-сервер, который сам раздает IP-адреса, приведите файл к следующему виду (замените enp0s3 на имя вашего интерфейса):

network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: true

## Вариант Б. Ручная настройка (Статический IP-адрес)
Если вам нужно жестко закрепить за сервером определенный IP, используйте такую структуру (подставьте ваши сетевые данные):

network:
  version: 2
  renderer: networkd
  ethernets:
    enp0s3:
      dhcp4: false
      addresses:
        - 192.168.1.100/24
      routes:
        - to: default
          via: 192.168.1.1
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1


* 
* addresses — желаемый IP-адрес сервера. Маска /24 соответствует стандартной маске 255.255.255.0.
* routes -> via — IP-адрес вашего основного шлюза (роутера), через который сервер будет выходить в интернет.
* nameservers -> addresses — адреса DNS-серверов (в примере указаны публичные DNS от Google и Cloudflare).
* 

------------------------------
## Шаг 4. Применение настроек

   1. Перед окончательным применением обязательно протестируйте конфигурацию на наличие синтаксических ошибок:
   
   sudo netplan try
   
   Если всё сделано правильно, система попросит нажать Enter для подтверждения. Если вы настраиваете сервер удаленно и связь прервется, через 120 секунд Netplan автоматически откатит настройки назад, и вы не потеряете доступ.
   2. Если тест прошел успешно, примените настройки на постоянную основу:
   
   sudo netplan apply
   
   
------------------------------
## Шаг 5. Проверка работы
Убедитесь, что настройки применились и сеть работает:

# Проверить новый IP-адрес
ip a
# Проверить доступность интернета и DNS
ping -c 3 google.com

Если после этого ping пошел успешно, вы можете возвращаться к обновлению пакетов через sudo apt update.
